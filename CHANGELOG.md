# Changelog

All notable changes to TapKey are listed here.

## [1.0.0] - 2026-09-04

### Added

- One, two, and three-tap actions.
- Custom keyboard shortcuts, text, URLs, and applications.
- Adjustable motion sensitivity with Very High as the default.
- Automatic restart after Accessibility permission is granted.
- A private motion-sensor design with no microphone or network access.
